# AI 功能实现检查清单

## 产品行为

- [ ] MVP 范围与 PRD 一致，未引入无关功能
- [ ] 首次进入、无输入、处理中、成功、失败、重试状态完整
- [ ] 输入格式、大小、数量、权限和额度均有校验
- [ ] 结果可预览、使用、保存或按需求导出

## AI 与服务端

- [ ] 模型请求有超时、重试边界和幂等处理
- [ ] Provider 错误被映射为用户可理解的错误码
- [ ] 模型返回被 schema 或等价方式校验
- [ ] 任务状态不会因刷新、重复点击或网络抖动而错乱
- [ ] 成本、额度和并发限制符合产品规则

## 安全与隐私

- [ ] 涉及人脸、声音、身份或其他个人数据时，明确授权与滥用限制
- [ ] 不在日志中记录不必要的原始媒体、提示词或个人信息
- [ ] 媒体留存、删除、分享和举报行为符合产品现有规则

## 验证

- [ ] 通过相关单元测试或集成测试
- [ ] 通过 lint、类型检查和构建（仓库提供时）
- [ ] 手动验证一条成功路径和一条可恢复失败路径
- [ ] 埋点名称和属性与 PRD 一致
